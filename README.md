Consulta periódica

Interface estática para explorar o dataset de perovskitas duplas por elementos da tabela periódica, tier e posição na estrutura.

Publicação

Site estático pelo GitHub Pages na branch main e pasta raiz. Os arquivos de dados ficam em data/ e são carregados pelo navegador.

Recursos

- Busca por elementos, fórmula e posições A, B, B′ e X.
- Listas Tier A final, Tier A preliminar, Tier B e exploratória.
- Ficha com campos do ranking, descritores e dados adicionais.
- Índice com 188.314 estruturas canônicas.

Tiers e propriedades são resultados computacionais. Similaridade experimental não é uma probabilidade calibrada de sucesso em laboratório.
